# XSSを極める教科書 ― AI・自動スキャナが苦手なXSSを見つけるために

> 反射型 `<script>alert(1)</script>` の**先**にある、DOMデータフロー推論・mXSS・サニタイザ/CSP回避・プロトタイプ汚染・DOM clobbering・script gadgets・フレームワーク固有sink を、基礎から最先端まで8段階で体系的に学ぶための日本語教科書です。

この教科書は、多数のXSS学習資料（PortSwigger、OWASP、Bentkowski、Kinugawa、Sonar、Google Research、Beyond XSS、HackTricks、Flatt Security、徳丸浩ほか）の内容を実際に取得・精読し、**日本語でわかりやすく書き起こした**ものです。専門用語は使いますが、初出時に必ずかみ砕いて説明します。

## この教科書の読み方

- **順番に読むのが基本**です。各章は前章の知識を前提に積み上がります。ただし、既に基礎がある方は、目次から必要な章（特に第4章）へ直接飛んでも構いません。
- **専門用語はその場で説明します**。例：「sink（ユーザー入力が最終的に実行・解釈される危険な代入先）」。初出以降は説明を省くことがあるので、忘れたら付録の用語集を参照してください。
- **コード例・ペイロードは「なぜ動くか」とセットで**書いてあります。写経するだけでなく、原理を理解してください。それが自動ツールに勝つための力です。
- **手を動かす**：第7章のハンズオンと連動させ、読んだ技法を PortSwigger のラボで実際に試してください。

## 対象読者

- 反射型・格納型の素朴なXSSは理解しているが、より高度な領域を体系的に学びたい中〜上級の学習者。
- バグバウンティやセキュリティ診断で「自動ツールが見つけられないXSS」を狙いたい人。
- 防御側として、最新の攻撃手法とその対策（Trusted Types、strict CSP等）を理解したい開発者・セキュリティエンジニア。

## 重要な注意（詳細は序章 0.7 を参照）

- 本書がまとめた資料の多くは**二次資料**であり、著者独自の解釈を含みます。特にmXSS等は**一次資料の併読を推奨**します。
- バイパス手法は**ブラウザ/ライブラリのバージョン依存で陳腐化が速い**です。公開日と対象バージョンを必ず確認してください。
- 攻撃手法の検証は、**必ず認可されたスコープ内**で行ってください。無許可のテストは犯罪になり得ます。
- 本書の目的は、攻撃者の視点を通じて**より堅牢なアプリケーションを守ること**にあります。

## ⚠️ 本教科書の作られ方と重要な限界（必読）

この教科書は、クラウド上のサンドボックス環境で生成されました。**その環境のネットワーク送信（egress）プロキシが、XSSドキュメントを提供する主要ドメインのほぼ全て**（portswigger.net、owasp.org、medium.com、speakerdeck.com、flatt.tech、research.securitum.com、sonarsource.com、hacktricks.wiki、web.dev、research.google、blackhat.com、cure53.de、blog.tokumaru.org など）への直接アクセスをブロックしました。結果として、**指定された約89件の資料のうち61件は、ページ本体を直接取得できませんでした**。

そのため本書の内容は、次の方法で復元されています。

- WebSearch（検索エンジン）の要約・スニペット
- 到達できた一部の一次ソース（GitHub上の DOMPurify 公式Wiki/回帰テスト、`aemkei/jsfuck` リポジトリ、CVE登録情報、各PR など）

これは次の2点を意味します。

1. **各資料の「⚠️ 未取得の資料」注記**が本文の該当箇所に入っており、URLと理由を明示しています（ユーザーご指定の要件）。取得できなかった資料は、そのURLからご自身で直接ご覧ください。まとめは[付録B（99-appendix.md）](./99-appendix.md)にあります。

> 補足：ネットワーク制限のない環境（ローカルのBurp Suite併用など）で同じ資料を直接読み直せば、より原典に忠実な版に更新できます。ご希望があれば、その方針での再生成も可能です。
