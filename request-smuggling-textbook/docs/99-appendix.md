## 付録C：用語集

- **HTTPリクエストスマグリング / デシンク攻撃**：フロントエンドとバックエンドがHTTPリクエストの境界を異なって解釈することを突き、後続リクエストへ任意のプレフィックスを注入する攻撃。
- **CL.TE**：フロントエンドが`Content-Length`を、バックエンドが`Transfer-Encoding`を優先することで生じるデシンク。
- **TE.CL**：フロントエンドが`Transfer-Encoding`を、バックエンドが`Content-Length`を優先することで生じるデシンク。
- **TE.TE**：両者とも`Transfer-Encoding`を扱うが、片方だけが難読化されたヘッダを無視することで生じるデシンク。
- **CL.0**：バックエンドが特定のリクエストで`Content-Length`を無視し（0として扱い）、ボディが次のリクエストとして解釈される変種。
- **H2.CL / H2.TE / H2.0**：HTTP/2からHTTP/1.1へのダウングレード時に、擬似的な長さ情報の不整合を突く変種。
- **クライアントサイドデシンク (CSD)**：被害者のブラウザ自身にデシンクを起こさせ、通常は到達できない接続にリクエストを注入する手法（Browser-Powered Desync）。
- **single-packet attack**：1つのTCPパケットに複数リクエストを詰め、ネットワークジッタを排除して競合状態を高精度に突く技法（Smashing the State Machine, 2023）。
- **レスポンスキュー汚染 (RQP)**：接続上のレスポンスの順序をずらし、あるユーザーのレスポンスを別ユーザーに配送させる高深刻度の帰結。
- **リクエストトンネリング (request tunnelling)**：フロントエンドが接続を再利用しない条件下でも、単一接続内でリクエストを密輸する手法。
- **Webキャッシュポイズニング**：キャッシュキーに含まれない入力（unkeyed input）を使って、キャッシュに悪意ある応答を保存させ他ユーザーへ配信する攻撃。
- **Webキャッシュデセプション (WCD)**：パスの混同を利用し、機密を含む動的応答を静的リソースとしてキャッシュさせ盗み出す攻撃。
- **h2c smuggling**：HTTP/2 cleartext（h2c）へのアップグレードを悪用し、プロキシのアクセス制御を迂回する手法。
- **unkeyed input**：キャッシュの一意性判定（キャッシュキー）に含まれないが応答内容に影響する入力。キャッシュポイズニングの起点。
