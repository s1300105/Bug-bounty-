# 序章：本書の狙いと OAuth 脆弱性の全体像

## なぜ OAuth を「極める」のか

OAuth 2.0 と OpenID Connect（OIDC）は、いまや「他サービスでログイン」「サードパーティ連携」「API アクセス委譲」の事実上の標準です。裏を返せば、ここが崩れると **アカウント乗っ取り（ATO）** という最上級の影響に直結します。実際、公開バグバウンティでも OAuth 系の不備は最頻出かつ高報奨のクラスであり、Bhavuk Jain の Sign in with Apple（$100,000）、Youssef Sammouda の Facebook/Oculus ATO（$44,250）など、大型の事例が数多く積み上がっています。

重要なのは、**OAuth の脆弱性の多くは「プロトコルの欠陥」ではなく「仕様が柔軟すぎて実装者が細部を誤る」ことに起因する**という点です。したがって本書は、「正しいフロー」と「実装がどこで崩れるか」を常に対で提示します。この 2 つを結び付けて理解できると、暗記に頼らず、未知のアプリでも当たりを付けられるようになります。

## 本書の構成（5段階）

本書はロードマップの 5 段階に対応した 5 章構成です。

1. **第1章 基礎理解** — 4ロール（Resource Owner / Client / Authorization Server / Resource Server）、各フロー（Authorization Code / Implicit / Client Credentials / Device / PKCE）、access/ID/refresh トークンの違い、OIDC の `id_token` 検証。攻撃は「正常フローのどのステップが崩れるか」を突くので、まずここを正確に押さえます。
2. **第2章 脆弱性クラス【核心】** — redirect_uri 検証不備／open redirect、state 欠如（CSRF・強制プロファイルリンク）、認可コード横取り/injection/replay、implicit のトークン漏洩、PKCE downgrade/bypass、scope upgrade、mix-up、JWT（`alg=none`・key confusion・weak secret）と id_token 検証不備。各クラスを「発生条件・検出・悪用・対策」のパターンとして持ちます。
3. **第3章 実例ライトアップ【核心】** — Frans Rosén「dirty dancing」、Egor Homakov の古典、Salt Labs の access token 未検証 3 部作、公開 HackerOne レポート、設定不備の連鎖による ATO。攻撃者の思考を学びます。
4. **第4章 安全な環境での検証演習と方法論** — 許可された演習環境（ラボ）が題材にする論点を原理レベルで整理し、脅威モデル／チェックリストで漏れなく回す方法論を身につけます。**特定ラボの攻略手順そのものは扱いません。**
5. **第5章 発展と最新動向** — OAuth 2.1、Security BCP（**RFC 9700 / BCP 240**、2025年1月発行）、DPoP（RFC 9449）、FAPI 1.0/2.0、MCP の認可課題まで。

## 前提知識

- HTTP（メソッド・ステータス・ヘッダ・クッキー・リダイレクト）とブラウザのセキュリティモデル（同一オリジンポリシー、CORS の基本）。
- URL の構造とパーサの挙動（スキーム・ホスト・パス・クエリ・フラグメント）。
- JSON と、できれば JWT の 3 分割構造（header.payload.signature）。

これらに不安があれば、本リポジトリの「クライアントサイド脆弱性ハンティングの基盤技術を極める教科書」を先に読むと土台が固まります。

## スコープと倫理（必読）

本書は防御・脆弱性理解・正当なセキュリティ教育／バグバウンティのための教材です。攻撃技法は仕組みの理解と防御のために解説しており、**実在サービス・本番環境への無許可検証や破壊的手順は記載しません**。OAuth は「他人のアカウント／連携先」に容易に到達しうる性質があるため、検証は必ず自分が所有または明示的に許可された環境に限り、バグバウンティのスコープと規約を厳守してください。

それでは、[第1章 基礎理解](01-fundamentals.md) から始めましょう。
