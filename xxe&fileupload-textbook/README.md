# XXE & ファイルアップロードを極める教科書

XXE（XML外部実体注入）とファイルアップロード脆弱性を、初級者から専門家まで段階的に解説する日本語教科書です。URL 付き学習ロードマップ（`../roadmaps/xxe&fileupload.md`）の各資料を**原典から取得して**章立てに再構成しました。

- **本文は [`docs/`](./docs/) にあります。** 入口は [`docs/index.md`](./docs/index.md)（目次・使い方・限界）。
- 全11章 + 序章 + 付録（付録A: 全URL / 付録B: 未取得資料 / 付録C: 用語集 / 付録D: 参考書籍）。
- **核心は第3・4・7・8章**（Blind XXE／各種ファイル形式経由 XXE／アップロード検証バイパス／RCE 昇格）。
- 構成は **Part A：XXE（第1-5章）→ Part B：ファイルアップロード（第6-8章）→ Part C：統合・実例・防御（第9-11章）**。

## スコープ

防御・脆弱性理解・正当なセキュリティ教育／バグバウンティのための教材です。実在サービス・本番環境への無許可検証や破壊的手順（DoS・billion laughs・zip bomb 等）、特定ラボの攻略手順は記載していません。OOB（帯域外）通信は自分の管理下のサーバのみに向け、検証は自分が所有または明示的に許可された環境でのみ行ってください。

## ローカルで本 UI（サイドバー＋全文検索）にする

```bash
pip install mkdocs-material
cd xxe\&fileupload-textbook
mkdocs serve
# → http://127.0.0.1:8000
```

サイドバーは `docs/` の `00- 01- .. 99-` のファイル名順に自動生成されます。GitHub 上では `docs/index.md` からリンクをたどっても読めます。
