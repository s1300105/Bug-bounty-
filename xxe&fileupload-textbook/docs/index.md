# XXE & ファイルアップロードを極める教科書

XXE（XML外部実体注入）とファイルアップロード脆弱性を、**初級者から専門家まで**段階的に深掘りするための日本語教科書です。バグバウンティ・脆弱性リサーチ・防御設計の実務に耐える密度を目標に、`roadmaps/xxe&fileupload.md`（URL 付き学習ロードマップ）の各資料を**原典から取得して**章立てに再構成しました。

> **本書のスコープ（重要）**
> 本書は**防御・脆弱性理解・正当なセキュリティ教育／バグバウンティ**のための教材です。攻撃技法は「なぜ成立するのか」という仕組みの理解と、それを踏まえた防御設計のために解説しています。**実在サービス・本番環境への無許可の検証や、破壊的な手順（DoS・billion laughs・zip bomb 等）は記載しません**。特定の演習環境（ラボ）を解くための攻略手順そのものも本書の目的ではありません。手を動かす際は、必ず自分が所有する、または明示的に許可された環境（PortSwigger 等の無償ラボ、意図的に脆弱なローカル環境、スコープ内のバグバウンティ対象）でのみ行い、OOB（帯域外）通信は**自分の管理下のサーバのみ**に向けてください。

## この本の使い方

- XXE とファイルアップロードは「入力パース」の欠陥という共通の根を持ち、**SVG／DOCX/XLSX/PPTX（XMLベースのアップロード）で交差**します。この交差点こそが「武器化の核」です。まず第1章（XML/DTD の仕組み）で土台を固め、第3章（Blind XXE）・第4章（各種ファイル形式経由 XXE）・第7章（アップロード検証バイパス）・第8章（RCE 昇格）の**★核心章**に進んでください。
- 学習は **「正しい仕様」と「パーサ／検証がどこで崩れるか」を対で覚える**のが効率的です。XXE は「XML の正当な仕様（DTD・実体）」の悪用であり、アップロードは「拡張子・MIME・マジックバイト・実行可否」の検証欠落の連鎖です。
- **Blind XXE（OOB）が実力差の出る領域**です。レスポンスに実体が反映されない現実の対象で、外部 DTD のホスティング・パラメータ実体のネスト・エラーベース抽出・**ローカル DTD 再利用**を手癖にすることが到達目標です（第3章）。
- **「XML を解釈しうる入口」を見たら XXE を疑う**——画像アップロード（SVG）、履歴書アップロード（DOCX）、SAML/SOAP/XML-RPC、RSS、XMP メタデータ。この嗅覚が第4章の勘所です。
- 各節の末尾には `> 出典: 記事名 — URL` を明記しています。原典に当たる習慣をつけてください。取得できなかった資料は本文中に `⚠️ 未取得の資料` として明示し、**付録B**に一覧化しています。

## 本書の限界

- 一部の walkthrough は個人ブログ / Medium / GitBook ミラー由来で、ラボ更新により手順が古くなる可能性があります。必ず一次資料（PortSwigger, OWASP, ベンダーアドバイザリ）で答え合わせをしてください。
- 生成時に原典を直接取得できなかった資料が **18件** あります（HTTP 403/404・DNS 解決失敗・TLS 検証エラー・接続リセット・動的レンダリング・PDF バイナリなど）。該当箇所は本文に `⚠️ 未取得の資料` として明示し、WebSearch の要約・GitHub raw ミラー・同一著者の一次資料等で補完しています。詳細は[付録B](99-appendix.md)。
- Facebook 事例の**報奨額には表記揺れ**があります（Careers/Ramadan は SecurityWeek が $6,300・Threatpost が「$6,000 超」、OpenID/Silva の $33,500 は当初 arbitrary file read → 後に potential RCE へ再分類）。本書はこの揺れを本文で明示しています。
- **ImageTragick（CVE-2016-3714）は 2016 年の脆弱性**です。学習素材としては優秀ですが、現行の報奨対象になるかは対象環境（policy.xml 設定・ImageMagick バージョン）次第です。
- 本書は「手法・思考プロセス」を学ぶための教材です。HackerOne 公開レポートの一部は伏字であり、学ぶべきは対象情報ではなく**再現可能な原理**です。
