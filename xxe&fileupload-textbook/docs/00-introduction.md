# 序章：本書の狙いと XXE / ファイルアップロードの全体像

## この2分野をなぜ一冊にまとめるのか

XXE（XML External Entity injection）とファイルアップロード脆弱性は、一見すると別ジャンルに見える。しかし両者は **「サーバがユーザー入力をパースする」際の欠陥** という共通の根を持ち、現実の攻撃面では次の一点で交差する——**SVG・DOCX・XLSX・PPTX といった「XML を内包するファイル」のアップロード**である。

- 画像アップロード欄に **SVG**（XML ベース）を投げれば、サーバ側の画像処理ライブラリ（Apache Batik 等）が XML をパースし、XXE が発火しうる。
- 履歴書アップロード欄に **DOCX / XLSX**（ZIP 内に複数の XML を含む OOXML）を投げれば、文書変換・プレビュー生成の過程で内部 XML がパースされ、XXE が発火しうる。

つまり「ファイルアップロード機能」は、しばしば「気づかれにくい XML パーサへの入口」である。これが、既に学んだ SSRF・SSTI/RCE・デシリアライゼーションと接続する **武器化の核** になる。

## 武器化の3つの核

本書全体を貫く「実力差が出る」到達点は次の3つだ。

1. **盲目 XXE（OOB）による exfiltration**（第3章）
   レスポンスに実体が反映されない現実の対象で、攻撃者が自前サーバに**外部 DTD** をホストし、**パラメータ実体のネスト**でファイル内容を URL に載せて送出する。OOB が遮断された環境では、標的ホストに元から存在する**ローカル DTD を再利用**するエラーベース手法（Arseniy Sharoglazov, 2018 年 Top 10 Web Hacking Techniques 7位）が効く。ここは自動ツールが最も苦手とし、人間の理解が前提となる領域。

2. **XML を解釈する各種ファイル形式経由の XXE**（第4章）
   SVG／OOXML／PDF／SAML／SOAP／XMP メタデータ——「XML と気づかれにくい入口」を列挙し、`oxml_xxe` / `officeXXE` / `office-open-xml-editor` で自作のテストファイルにペイロードを埋め込めること。

3. **アップロード検証バイパスから RCE への昇格**（第7・8章）
   拡張子・Content-Type・マジックバイト・`.htaccess` の各バイパスを使い分けて Web シェルを設置し、ImageTragick（CVE-2016-3714）等の画像処理ライブラリ経由 RCE や Zip Slip を再現できること。「アップロードできた」で止めず、**影響（file 読取 / SSRF / RCE / Stored XSS）まで示す**のが報奨の核心。

## 判断のためのシグナル（勘所の早見表）

現実の対象で「何を疑うか」を素早く決めるための分岐を、序章に集約しておく。各章で詳述する。

- **XML を受け付ける入口を見たら XXE**：`Content-Type: application/xml`、`.xml`/`.svg`/`.docx`/`.xlsx` アップロード、SAML `SAMLResponse`、SOAP エンドポイント、RSS/Atom 取り込み。
- **実体がレスポンスに返らないなら Blind へ切り替え**：まず Collaborator（OAST）で外部到達を確認 → 外部 DTD で exfil → OOB 遮断ならローカル DTD 再利用のエラーベースへ。
- **`file://` が読めたら次は SSRF**：`http://169.254.169.254/`（クラウドメタデータ）へ。XXE と SSRF は地続き。
- **画像アップロードで拡張子が緩いなら**：SVG（XXE/XSS）→ 実行可能拡張子（Web シェル）→ ImageMagick 経由（ImageTragick）の順に試す。
- **拡張子ホワイトリストがあっても**：`.htaccess`/`web.config` で実行を有効化、二重拡張子、代替拡張子（`.phtml`/`.php5`/`.phar`）、polyglot、パストラバーサル（`../`）を検討。

## 学習の進め方（目安）

ロードマップの週割りを踏襲する。既に SSRF/SSTI/デシリアライゼーションを学習済みなら第2・5・8章の関連箇所は短縮できる。

1. **Lv1-2（第1-2章）**：日本語資料で基礎を固め、古典的 XXE の 3 パターン（file 取得・SSRF・XInclude）を理解する。
2. **Lv3（第3章）★重点**：外部 DTD を自前環境にホストし、Blind XXE の exfil とローカル DTD 再利用を体得する。
3. **Lv4（第4章）★重点**：OOXML/SVG にペイロードを埋め込むツールを使いこなし、XML を含む入口を列挙する。
4. **Lv5（第5章）**：UTF-16/PUBLIC/expect:// を実験し、WAF 回避と XXE→RCE 条件を説明できるようにする。
5. **Lv6-8（第6-8章）★重点**：アップロード検証の各バイパスを引き出しにし、ImageTragick / Zip Slip を理解する。
6. **Lv9-11（第9-11章）**：実例レポートを精読し、防御チートシートから「なぜ回避できるか」を逆算する。

## 停止・エスカレーション基準（必読）

- 実対象では**必ずスコープとルール**を確認する。
- OOB 通信は**自分の管理下のサーバのみ**に向ける。第三者の Collaborator ドメインや無関係なサーバへデータを送出しない。
- **DoS（billion laughs／再帰的実体展開／zip bomb）は明示的な許可がない限り実行しない**。本書もこれらの破壊的手順は原理説明にとどめ、実行可能な形では記載しない。
- ファイル読取で得た機微情報（秘密鍵・認証情報）を保存・再利用しない。PoC は「読み取れたこと」を示す最小限にとどめる。
