# AIセキュリティを極める教科書

AI／LLMを組み込んだアプリケーションのセキュリティ脆弱性を、**初級者から専門家まで**段階的に深掘りするための日本語教科書です。バグバウンティ・脆弱性リサーチ・防御設計の実務に耐える密度を目標に、`roadmaps/ai.md`（URL付き学習ロードマップ）の各資料を**原典から取得して**章立てに再構成しました。

> **本書のスコープ（重要）**
> 本書は**防御・脆弱性理解・正当なセキュリティ教育／バグバウンティ**のための教材です。攻撃技法は「なぜ成立するのか」という仕組みの理解と、それを踏まえた防御設計のために解説しています。**実在サービス・本番環境への無許可の検証や、破壊的な手順は記載しません**。特定の演習環境（ラボ・CTF）を解くための攻略手順も本書の目的ではありません。手を動かす際は、必ず自分が所有する、または明示的に許可された環境でのみ行ってください。

---

## この本の使い方

- LLM関連の脆弱性の多くは「LLM特有の新しい弱点」ではなく、**従来型Web脆弱性（XSS・SSRF・コマンドインジェクション・デシリアライズ等）が、LLMという新しい入力生成者・命令の翻訳者を経由して新たな到達経路を得たもの**です。学習は「LLMの仕組み」と「従来型脆弱性の原理」を対で押さえるのが効率的です。
- **受理される本命は第3章（従来型Web脆弱性への接続）と第2章（間接プロンプトインジェクション）、第6章（サプライチェーン／実CVE）**です。既存のWeb／デシリアライズの知識がそのまま通用します。
- 各節の末尾には `> 出典: 記事名 — URL` を明記しています。原典に当たる習慣をつけてください。
- 取得できなかった資料は本文中に `⚠️ 未取得の資料` として明示し、**付録B**に一覧化しています。

## 推奨学習パス

1. **土台**: 第1章で攻撃面（プロンプト／システムプロンプト／RAG／tool calling／エージェント／MCP）と信頼境界、脅威分類（OWASP LLM Top 10／MITRE ATLAS／NIST AI RMF）を把握する。
2. **起点**: 第2章で直接／間接プロンプトインジェクションと、なぜ根本解決が困難か（指示とデータが構造的に分離されない）、lethal trifectaを理解する。
3. **本命**: 第3章でInsecure Output Handling→XSS/RCE/SSRFへの接続を、従来型脆弱性の原理と対応づけて学ぶ。バグバウンティで最も受理されやすい領域。
4. **拡張**: 第4章（エージェント／MCP）・第5章（RAG／データ）で、自律性と外部データ取り込みが生む新しい攻撃面を押さえる。
5. **現実的な稼ぎ場**: 第6章でpickle RCE・MLOps／LangChainの実CVE・huntrを学ぶ。既存スキルがそのまま通用する。
6. **事例で思考を学ぶ**: 第7章で大手製品の実修正事例（Bing Chat／Bard／Copilot／ChatGPT）を読み、攻撃者の当たりの付け方を内面化する。
7. **手を動かす・継続**: 第8章の許可された演習環境とスキャナ、第9章のレッドチーミング方法論・マルチモーダル・書籍で継続的に鍛える。
