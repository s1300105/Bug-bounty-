## 付録C：用語集

| 用語 | 説明 |
| --- | --- |
| ATO (Account Takeover) | アカウント乗っ取り。攻撃者が正当な利用者のアカウントを完全に制御する状態。認証系脆弱性の最終的な高インパクト目標。 |
| JWT (JSON Web Token) | ヘッダ・ペイロード・署名の3部からなる署名付きトークン。`alg` の取り違えや `kid`/`jku`/`jwk` の悪用が代表的な攻撃面。 |
| alg混同 (Algorithm Confusion) | RS256（非対称）で発行されたトークンを HS256（対称）として検証させ、公開鍵を HMAC 鍵に流用して署名を偽造する攻撃。 |
| kid / jku / jwk | JWTヘッダの鍵参照パラメータ。検証側が信頼せずに参照すると、パストラバーサル・SSRF・任意鍵注入につながる。 |
| SAML | XMLベースのフェデレーション認証プロトコル。IdP が発行する署名付きアサーションを SP が検証する。 |
| XSW (XML Signature Wrapping) | 署名対象のXML要素を移動・複製し、検証される要素と処理される要素をずらして署名検証を迂回する攻撃。 |
| WebAuthn / FIDO2 / パスキー | 公開鍵暗号ベースのパスワードレス認証。認証器（authenticator）が鍵ペアを保持し、フィッシング耐性を持つ。 |
| AAGUID | 認証器のモデルを識別するID。サーバがこれを検証しないと任意の（仮想）認証器の登録を許してしまう場合がある。 |
| MFA / 2FA | 多要素／二要素認証。「知識・所持・生体」など異なる要素を組み合わせる。検証順序やレート制限の不備がバイパスの起点になる。 |
| OTP | ワンタイムパスワード。総当たり耐性・有効期限・使い捨て性・宛先固定の各観点で実装不備が生じやすい。 |
| リセットポイズニング | パスワードリセットのリンク生成時に Host ヘッダ等の外部制御値を混入させ、リセットトークンを攻撃者ドメインへ送らせる手口。 |
| IdP / SP | Identity Provider（認証を提供する側）／ Service Provider（認証結果を受け取る側）。SAML/OIDC の基本ロール。 |

## 付録D：参考書籍・継続学習

- **The Web Application Hacker's Handbook**（Dafydd Stuttard, Marcus Pinto）— 認証・セッション管理の章は、本書の各クラスの土台となる古典。
- **Real-World Bug Hunting**（Peter Yaworski）— 認証周辺の連鎖を含む、実報告ベースの学習に有用。
- **PortSwigger Web Security Academy** — 認証・JWT・MFA・OAuth の無償ラボと解説。手を動かす学習の中心に据えると良い。
- **OWASP Web Security Testing Guide (WSTG) / Cheat Sheet Series** — 認証テストの体系的チェックリストと防御の共通合意。
- **jwt_tool / SAML Raider / Burp JWT Editor** の各公式ドキュメント（第8章参照）。
