# 序章：本書の狙いと認証脆弱性の全体像

## なぜ「認証」を一冊にまとめるのか

認証（Authentication）は「あなたが本当に主張どおりの人物か」を確かめる仕組みであり、あらゆるアクセス制御の土台である。ここが崩れると、その上に積まれた認可（Authorization）やビジネスロジックがどれほど堅牢でも意味をなさない。だからこそ、バグバウンティにおいて認証系の欠陥は **アカウント乗っ取り（Account Takeover, ATO）** という最高クラスのインパクトに直結し、報奨額も大きくなりやすい。

一方で認証の脆弱性は、単一の「魔法の一撃」で成立することは稀である。多くの実例は、以下のような**認証まわりのワークフローに散らばった小さな不備の連鎖**として現れる。

- ログイン処理（ユーザー名列挙、ブルートフォース耐性、レスポンス差分）
- トークン・セッションの発行と検証（JWT の署名検証、SAML の署名検証、セッション固定）
- 多要素認証（MFA/2FA の検証順序、レート制限、OTP の再利用）
- パスワードリセット／メール変更などの**回復系導線**（トークン推測、ホストヘッダ汚染、宛先の取り違え）
- フェデレーション／パスワードレス（OAuth・SAML・WebAuthn/パスキーのクレデンシャル紐付け）

本書は、これら個別のクラスを正確に理解したうえで、**第7章でそれらを「ATO への統合」という視点で束ね直す**構成をとる。

## 本書の全体像（学習マップ）

```
第1章 全体像と基礎         … テスト観点・語彙・チェックリストの土台
   ├─ 第2章 JWT攻撃         … ステートレストークンの署名検証の破り方
   ├─ 第3章 SAML攻撃        … XML署名検証（署名ラッピング/XMLコメント/パーサ差異）
   ├─ 第4章 WebAuthn/パスキー … パスワードレスの実装ミスと紐付け不備
   ├─ 第5章 MFA/2FAバイパス   … 「二段目」を無効化・迂回する手法
   └─ 第6章 パスワードリセット … 回復系導線という最頻出の弱点
第7章 ATOへの統合          … 上記の連鎖で乗っ取りを組み立てる【核心】
第8章 ツールと実践          … jwt_tool / SAML Raider / Burp JWT Editor
第9章 実例・ライトアップ     … 公開報告から手口と報告作法を学ぶ
第10章 方法論・チェックリスト … 体系化と最前線の研究
```

初学者は第1章 →（興味のあるクラス）→ 第7章の順で読むと、「点」の知識が「線」につながる。すでに Web ハントの経験がある読者は、第2章・第3章・第5章・第6章を投資対効果の高い最頻出クラスとして優先すると良い。

## 前提知識

- HTTP の基礎（リクエスト/レスポンス、ヘッダ、Cookie、リダイレクト）
- Base64URL エンコードと、対称鍵（HMAC）／非対称鍵（RSA/EC）暗号の初歩
- Burp Suite など、リクエストを観察・改変できるプロキシツールの基本操作

これらは各章で必要に応じて補足するが、体系的な基礎は [`clientside-textbook`](../../clientside-textbook/docs/index.md) など他の教科書も併読すると理解が深まる。

## 倫理とスコープ（必読）

本書は防御・脆弱性理解・正当なセキュリティ教育のための教材である。攻撃技法は「なぜ成立するのか」を説明するために解説しており、**実在サービスや本番環境への無許可の検証、破壊的な手順、特定ラボの攻略手順は記載しない**。検証は必ず、自分が所有するか明示的な許可を得た環境で、書面による許可の範囲内で行うこと。無許可のアクセスは多くの国で法的責任を伴う。
