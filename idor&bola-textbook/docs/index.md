# IDOR/BOLA・アクセス制御・ビジネスロジックを極める教科書

IDOR/BOLA（オブジェクトレベル認可の不備）、アクセス制御バイパス、ビジネスロジック脆弱性を、**初級から専門家レベルまで**、原典に忠実に日本語で解説する教科書です。自動スキャナが最も苦手とし、バグバウンティで最大級の報奨を生むこの領域を、「属人的な勘」から「網羅的・体系的な武器（方法論）」へと引き上げることを狙いとします。ロードマップの Lv1（全体像/モデル）→ Lv10（方法論/思考法）に沿って、10章＋序章＋付録で段階的に積み上げます。

> **本書のスコープ（重要）**
> 本書は**防御・検出・安全な検証の理解を目的**として記述しています。実在するサービスや本番環境への無許可のテストは、その国・地域の法律やサービス規約に違反する可能性があり、決して行ってはいけません。とりわけ **cross-tenant（テナント越境）・レースコンディション・IDORの検証は、他ユーザー・他テナントの実データに副作用を及ぼしうる**という固有のリスクを持つため、本書では破壊的手順や実運用ペイロードの完成形ではなく、**なぜ脆弱になるのか（原理）・どう検出するのか・どう防ぐのか**を中心に据えています。手を動かす学習は、PortSwigger Web Security Academy などの**公式に用意された演習ラボ**か、自分で構築した検証環境、または**明示的に許諾されたスコープ内資産**でのみ行ってください。責任ある開示（responsible disclosure）を徹底してください。

## 使い方

1. **順番に読む**のが基本です。第1章のアクセス制御モデルの語彙が土台になり、第2章のIDOR/BOLA体系化が以降すべての基礎になります。既にIDORを実践している方も、第1〜2章で「型」を固定してから第4章（ロジック）・第6章（cross-tenant）・第7章（API/GraphQL）へ進むと網羅性が跳ね上がります。
2. **原典を必ず開く**：各節は原典（PortSwigger・OWASP・Vickie Li・Corey Ball・実報告集など）へのリンクを豊富に含みます。本書は原典への道案内であり、深い理解は原典を読んで初めて得られます。
3. **手を動かすのは公式ラボで**：PortSwigger Web Security Academy には Access control / Business logic / Race conditions / GraphQL の無料ラボが多数あります。安全な環境で「検出→再現→防御確認」のサイクルを回してください。
4. **自分のチェックリストを作る**：第2章のバイパス技法、第10章の方法論を素材に、「参照出現箇所 × バイパス技法」の総当り手順書を1枚にまとめるのが到達目標です。

## 本書の限界

- 本書は**2次資料を含む原典の要約と地図**であり、原典そのものの置き換えではありません。特に James Kettle のレース研究や Corey Ball『Hacking APIs』、実報告集は、本書を読んだ後に必ず一次資料に当たってください。
- 一部の資料は生成時にネットワーク上で取得できませんでした（Medium/YouTube/Notion/一部ベンダーブログ等）。該当箇所は本文中に `⚠️ 未取得` として明示し、[付録B](99-appendix.md#付録b-未取得の資料)にURLと理由を一覧化しています。
- 攻撃技法・CVE・報奨額・統計値は時事性を持ちます。特に GraphQL 関連 CVE、ベンダー計測値（「BOLAはAPI攻撃の約40%」等）、OWASP Top 10 の版は執筆時点の理解に基づきます。手を動かす際は最新の公式アドバイザリ・規約を確認してください。
