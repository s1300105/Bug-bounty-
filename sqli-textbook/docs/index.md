# SQLiを極める教科書

SQLインジェクション（SQLi）を、初級者から専門家レベルまで**原典に忠実に**学ぶための日本語教科書です。バグバウンティ／脆弱性リサーチ／防御実務を志す中〜上級者を主な読者に想定し、権威ある一次・二次資料（PortSwigger、OWASP、HackTricks、PayloadsAllTheThings、IPA、ベンダー研究など）の内容を、原理レベルで理解できるよう再構成しています。

本書は「[SQLインジェクション習得ロードマップ]」を土台に、各資料を実際に取得して要約・解説したものです。リンク集ではなく、**読んで理解が完結する**ことを目指した教材です。

## 使い方

- **通読する**: 第1章から順に読むと、基礎 → in-band悪用 → blind/OOB → DB別技法 → WAF回避 → 応用・現代トピック → ツール → 防御 → 練習 → 長文リファレンス、と難易度順に積み上がります。
- **辞書的に引く**: 左サイドバー（章一覧）と各ページ右の目次（見出し一覧）、上部の全文検索を使って、必要な技法だけピンポイントで参照できます。
- **手を動かす**: 各章は「読む」だけでなく、対応する練習環境（PortSwigger Labs、sqli-labs、HTB Academy など）でのハンズオンと組み合わせることを前提にしています（第9章参照）。
- **原典に当たる**: 各節末に「出典」を明記しています。バージョン依存の構文や最新研究は、必ず原典で最新状態を確認してください。

## 本書の限界（重要）

- **教育・防御・許可された検証のための教材です。** テストは自分が所有する、または明示的に許可されたシステム（バグバウンティのスコープ内、意図的に脆弱なラボ）に対してのみ行ってください。実在サービス・本番環境への無許可の検証や、破壊的な手順は本書では扱いません。
- **陳腐化に注意。** SQLの構文・関数・ツールの挙動・WAFの防御はバージョンや時期に依存します。本書は執筆時点（2026年）の情報に基づきますが、実際に使う前に必ず現行バージョンで裏を取ってください。特に古い資料（例: pentestmonkey は2011年頃）は要照合です。
- **自動取得できなかった資料があります。** ログイン必須・Bot対策・リンク切れ等で本文に完全反映できなかった資料は、[付録B](99-appendix.md#付録b-未取得の資料)に理由つきで一覧化しています。該当箇所は本文中にも警告を挿入しています。
