# SSRFを極める教科書

サーバサイドリクエストフォージェリ（SSRF）を、**初級者から専門家まで**段階的に深掘りするための日本語教科書です。バグバウンティ・脆弱性リサーチ・防御設計の実務に耐える密度を目標に、`roadmaps/ssrf.md`（URL付き学習ロードマップ）の各資料を**原典から取得して**章立てに再構成しました。

> **本書のスコープ（重要）**
> 本書は**防御・脆弱性理解・正当なセキュリティ教育／バグバウンティ**のための教材です。攻撃技法は「なぜ成立するのか」という仕組みの理解と、それを踏まえた防御設計のために解説しています。**実在サービス・本番環境への無許可の検証や、破壊的な手順は記載しません**。手を動かす際は、必ず自分が所有する、または明示的に許可された環境（意図的に脆弱なラボ等）でのみ行ってください。SSRF は性質上スコープ外の内部/第三者システムへ容易に到達するため、許可範囲の確認を徹底してください。

## この本の使い方

- 各章は「読む＋手を動かす」がセットになる構成です。概念を読んだら、対応する PortSwigger の無償ラボなどで必ず再現してください。
- **核心は第5章（URLパーサ／フィルタ回避）と第6章（プロトコルスマグリング→RCE）**です。SSRF の「浅い／深い」を分けるのはこの2つなので、ここに時間を投資してください。
- 各節の末尾には必ず `> 出典: 記事名 — URL` を明記しています。原典に当たる習慣をつけてください。
- 取得できなかった資料は本文中に `⚠️ 未取得の資料` として明示し、**付録B**に一覧化しています。

## 推奨学習パス（8週間）

1. **第1〜2週（基礎＋基本悪用）**: 第1〜2章。PortSwigger の basic SSRF ラボ2つを解く。file:// 読み取りと時間差ポートスキャンを手で試す。
2. **第3〜4週（Blind/OAST＋クラウド）**: 第3〜4章。OAST でコールバックを観測し、IMDSv1/v2 の差を理解する。
3. **第5〜6週（フィルタ回避【核心】＋スマグリング）**: 第5〜6章。フィルタ回避ラボ3つを全消化し、Orange Tsai を通読。ローカルの脆弱環境で gopher→Redis を再現。
4. **第7〜8週（応用＋防御）**: 第7章と第9章。視点を反転し、脆弱なコードを allowlist ＋名前解決後の IP ピン留め＋スキーム制限で修正できるようにする。
5. **継続**: 第10章。PortSwigger Research を購読し、公開レポートを定期的に読む。

> **「専門家」と名乗れる閾値**: 未知のアプリでフィルタ回避を要する SSRF を発見し、クラウドメタデータ奪取またはプロトコルスマグリングで意味ある影響まで（許可された環境で）実証でき、明確で実行可能な修正案を書ける。

## 本書の限界

- 攻撃技法の深掘りは原典の多くが英語です。本書は日本語で要点を通読できるようにしていますが、細部は必ず原典（各節の出典）に当たってください。
- バージョン依存・時事性のある内容（IMDSv2 の既定化、ラボURLの変更など）は執筆時点の情報です。対象バージョン/年を本文中に明記していますが、最新状況は各自で確認してください。
- 自動取得できなかった資料は**付録B**にまとめています。該当箇所は一般知識で補足していますが、原典の細部とは差異があり得ます。
