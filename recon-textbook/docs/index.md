# Reconを極める教科書

バグバウンティ／脆弱性リサーチの成否を最も大きく左右する **Recon（偵察、reconnaissance）** を、初級者の「手順の丸暗記」から、上級者の「Recon自体が武器になる」水準まで引き上げるための日本語教科書です。中〜上級者を主な読者に想定し、The Bug Hunter's Methodology（Jason Haddix）、ProjectDiscovery、Assetnote、NahamSec／TomNomNom、Intigriti／YesWeHack、HackTricks、そして日本語の一次資料（morioka12 氏ほか）の内容を、**原理レベルで理解が完結する**よう再構成しています。

本書は「Reconを武器化するロードマップ」（本リポジトリ `roadmaps/recon.md`）を土台に、各資料を実際に取得して要約・解説したものです。リンク集ではなく、**読んで理解が完結する**ことを目指した教材です。

## 使い方

- **通読する**: 第1章から順に読むと、マインドセット → 資産発見 → サブドメイン列挙 → インターネット規模データ → コンテンツ／JS／OSINT → 歴史データ → 自動化 → 継続監視 → 方法論・実例、と「土台 → 差別化 → 武器化」の順に積み上がります。
- **辞書的に引く**: 左サイドバー（章一覧）と各ページ右の目次（見出し一覧）、上部の全文検索を使って、必要な技法だけピンポイントで参照できます。
- **手を動かす**: 各章は、必ず**自分が所有する、または明示的に許可された対象（バグバウンティのスコープ内・意図的に脆弱なラボ）**でのみ試してください。本書は特定サービスの攻略手順は扱いません。
- **原典に当たる**: 各節末に「出典」を明記しています。ツールのフラグや構文はバージョン依存が激しいため、必ず原典（公式ドキュメント）で最新状態を確認してください。

## 本書の限界（重要）

- **教育・防御・許可された検証のための教材です。** active列挙・ブルートフォース・クラウド資産へのアクセスは、対象プログラムのルールと法令の範囲内でのみ実施してください。ASN/IPレンジがクラウド共有基盤上にある場合、対象組織が管理していない資産が混ざりうるため、**必ず帰属（reverse DNS・証明書・WHOIS）を確認**してからテスト対象に含めてください。本書は実在サービス・本番への無許可検証や破壊的手順、特定のラボ攻略手順は扱いません。
- **陳腐化に注意。** ツールのフラグ・クエリ演算子・データソースの仕様は時期に依存します。本書は執筆時点（2026年）の情報に基づきますが、使用前に必ず現行バージョンで裏を取ってください。
- **誤検知に注意。** favicon hash相関やインターネット規模データソースは強力ですが、別組織の同一favicon等による誤検知を含みます。発見資産は帰属確認を経てから扱ってください。
- **自動取得できなかった資料があります。** 配信側のBot遮断・有料化・リンク切れ等で本文に完全反映できなかった資料は、[付録B](99-appendix.md#付録b-未取得の資料)に理由つきで一覧化し、該当箇所には本文中にも警告を挿入しています。
