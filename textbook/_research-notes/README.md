# 研究ノート（教科書の材料）

このディレクトリは、教科書本体（`textbook/` 直下の各章）を書くために、ロードマップに挙がった
約80本の資料URLを1本ずつ精読して作った日本語の詳細ノートです。合計で約285万字あります。

## なぜ残しているか
- この教科書は「実際に資料を読んで書いた」ことの証跡として、材料ノートを残しています。
- 本教科書の執筆環境（クラウドのサンドボックス）は多くのサイトへのアクセスが遮断されており、
  一度取得したこれらのノートは貴重です。原典が読めなくなったときの二次資料としても使えます。
- 各ノートの冒頭に「取得状況」表があり、どのURLを・どの経路で・どこまで取得できたか
  （full / partial / failed）が記録されています。

## ファイルの対応
- `00-retrieval-map.md` … この環境で実測した「どのURLがどの経路で取得できるか」の地図。
- `NN-<slug>.md` … ロードマップの各資料に対応する精読ノート（NN は資料番号）。

本教科書の読者は、まず `textbook/README.md`（目次）から各章を読んでください。
この研究ノートは、より深く一次に近い情報を確認したいとき、または教科書の記述の裏を
取りたいときに参照する補助資料です。
