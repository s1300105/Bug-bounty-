# バグバウンティ運用・戦略・自動化・収益化を極める教科書

すでに脆弱性の「武器」を揃えたハンターが、次に必要とする「**How（それらをどう束ねて実戦で回し、報奨を最大化するか）**」の運用体系を、URL付き学習ロードマップの原典に忠実に解説した日本語教科書です。プログラム選定・自動化基盤・レポート品質と報奨交渉・メンタル管理・収益化という運用の5領域を、TBHM／NahamSec／Critical Thinking Podcast／zseano／InsiderPhD らの二次資料を裏取りしながら、Lv1〜Lv9 の段階として全9章＋序章＋付録で構成しています。

## 読み方

- **GitHub上でそのまま読む**：[docs/index.md](docs/index.md) が入口（目次）です。各章へはそこからリンクしています。
- **本UI（サイドバー＋全文検索＋ダーク/ライト＋コードコピー）で読む**：

  ```
  python3 -m pip install --user mkdocs-material
  cd strategy\&manetaize-textbook
  mkdocs serve
  # http://127.0.0.1:8000 を開く
  ```

## 構成

- `docs/index.md` … 目次・使い方・本書の限界（サイトのホーム）
- `docs/00-introduction.md` … 序章（運用の5領域と Lv1〜Lv9 の登り方、現実認識）
- `docs/01-*.md` 〜 `docs/09-*.md` … 各章本文（★の第1・4・6・7章が運用の核）
- `docs/99-appendix.md` … 付録（全URL一覧・未取得資料・用語集・参考書籍）
- `sections/` … 生成時の節単位の中間ファイル（再生成用に保持）
- `mkdocs.yml` … MkDocs Material 設定
