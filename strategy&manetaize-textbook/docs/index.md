# バグバウンティ運用・戦略・自動化・収益化を極める教科書

すでに脆弱性の「武器」（Recon・XSS・SSRF・IDOR・認証・GraphQL など）を揃えたハンターが、次に必要とする「**How（それらをどう束ねて実戦で回し、報奨を最大化するか）**」の運用体系を、URL付き学習ロードマップの原典に忠実に日本語で解説する教科書です。個別の脆弱性技術ではなく、①プログラム選定と時間配分、②自動化基盤、③レポート品質と報奨交渉、④メンタル管理・燃え尽き対策、⑤収益化・コラボ・キャリアという「運用の5領域」を、Jason Haddix（TBHM）・NahamSec・Critical Thinking Podcast・zseano・InsiderPhD ら一流ハンターの二次資料を裏取りしながら、Lv1〜Lv9 の段階的ロードマップとして全9章＋序章＋付録で構成しています。

> **本書のスコープ（重要）**
> 本書は**防御・検出・安全な検証の理解、および持続可能な運用の習得を目的**として記述しています。実在するサービスや本番環境への無許可のテストは、その国・地域の法律やサービス規約に違反する可能性があり、決して行ってはいけません。手を動かす学習は、明示的にスコープが与えられたバグバウンティ対象か、PortSwigger Web Security Academy などの公式演習ラボ、あるいは自分で構築した検証環境でのみ行ってください。本書はラボの攻略手順は掲載しません。第5章の連鎖（chaining）で扱うペイロード例も、脆弱性がなぜ成立するかを理解し防御するための解説であり、破壊的操作を推奨するものではありません。

## この本の使い方

1. **まず[序章](00-introduction.md)** で全体像と、Lv1〜Lv9 の登り方を掴む。
2. 順に読み進めるのが基本だが、**★印の第1・4・6・7章が運用の核**。時間がなければここから読む。
3. 各章は「なぜ必要か → 何を習得するか → 原典に基づく解説 → 次章への橋渡し」で構成している。
4. 各節末に出典 URL を明記しているので、原典にあたって深掘りする。読む順序の指針は[序章](00-introduction.md)と[付録](99-appendix.md)にまとめた。

## 本書の限界

- 二次資料（商用ブログ・ポッドキャスト・SNS を含む）に基づく箇所があります。**収入額・受理率・報奨額などの数値は自己申告や特定時点の実績**であり、必ず一次情報や最新の公式発表で裏取りしてください。
- 生成時にネットワーク上の理由で取得できなかった資料は [付録B](99-appendix.md#付録b-取得できなかった資料) に URL と理由を明記しています。該当箇所は本文にも `⚠️ 未取得` 注記があります。
- 有料コース（TBHM Core $1,000、TBHM Expansion $200 など）への言及は事実の紹介であり、購入の推奨ではありません。まず無料の公開資料で土台を固め、費用対効果を見て投資判断してください。
