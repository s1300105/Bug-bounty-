## 付録C: 用語集

運用・戦略・収益化の文脈で頻出する用語を整理する。技術的脆弱性そのものの用語は各技術教科書に譲り、ここでは「How」に関わる語を中心に扱う。

| 用語 | 説明 |
|------|------|
| **TBHM** | The Bug Hunter's Methodology。Jason Haddix によるバグハンティング方法論。無料の公開talk（v4 Recon Edition / Application Analysis）と有料コース（Arcanum の Core $1,000、Expansion $200）がある。 |
| **VDP** | Vulnerability Disclosure Program。報奨金なしの脆弱性開示プログラム。広く浅く受け付ける傾向があり、reputation 稼ぎや練習に向く。 |
| **Public / Private プログラム** | 誰でも参加できる公開プログラムと、招待制の非公開プログラム。private は競争が少なく重複しにくいが、実績と reputation による招待が必要。 |
| **OoS (Out of Scope)** | スコープ外。テスト対象に含まれない資産・脆弱性クラス。OoS への報告は無効・reputation 毀損の原因になる。 |
| **duplicate（重複）** | 既に他のハンターが報告済みの脆弱性。判定は root cause が同一か（「最初の報告の修正でこの報告も直るか？」）で行われる。 |
| **triager（トリアージャー）** | プラットフォームやプログラム側で報告を初期審査・分類する担当者。良好な関係構築が signal と次の招待につながる。 |
| **signal / reputation** | プラットフォーム上のハンター評価指標。有効報告の比率や質で上下し、private 招待や優先度に影響する。 |
| **impact（インパクト）** | 脆弱性が現実に及ぼす被害。攻撃シナリオとして物語化することで報奨額が変わる、レポートの核。 |
| **chaining（連鎖）** | 単体では low/medium の脆弱性を組み合わせて critical へ昇華させる技法（例: Path Traversal → DLL hijacking → RCE）。 |
| **LHE** | Live Hacking Event。プラットフォーム主催の対面/オンライン集中ハッキングイベント。招待制で、収益安定化とコラボの梃子になる。 |
| **collaboration / split** | 複数ハンターで共同提出し報奨を分配する仕組み。HackerOne・Bugcrowd・Intigriti が公式機能を提供。 |
| **power law（べき乗分布）** | 収益がごく一部のトップに極端に集中する分布。バグバウンティ収入の実態を表す語。 |
| **burnout（燃え尽き）** | フィードバックループの断絶による意欲・生産性の低下。経験者ほど陥りやすい。 |
| **nuclei** | ProjectDiscovery の YAML ベース高速脆弱性スキャナ。カスタムテンプレート作成で真価を発揮する。 |
| **axiom** | 分散スキャン基盤。複数 VPS を動的に立てて Recon スループットを上げる。 |
| **notify** | ProjectDiscovery のツール。スキャン結果を Slack / Discord / Telegram へ通知し、継続監視パイプラインの終端を担う。 |
| **diff 検知（差分検知）** | 新規サブドメイン・エンドポイント・JS の変化を検出する仕組み。`anew` 等で実現し、「出力ではなく発見」を生む自動化の核。 |
| **VRT** | Vulnerability Rating Taxonomy。Bugcrowd の脆弱性分類・重大度基準。ノート整理のマスターリストにも使われる。 |

## 付録D: 参考書籍・継続学習リソース

本書は二次資料の統合であり、体系的な一冊を通読したい場合は以下が定番である（詳細と読む順序は[第9章](09-community-resources.md)を参照）。

- **Bug Bounty Bootcamp**（Vickie Li） — recon・方法論・自動化・レポートまで扱う、現代バグバウンティの「教科書」に最も近い一冊。
- **Real-World Bug Hunting**（Peter Yaworski） — 実際の報告例から脆弱性クラスを学ぶ。
- **Hacking APIs**（Corey Ball） — API 特化。既習の武器の統合先として好適。
- **Black Hat GraphQL** — GraphQL 深掘り。
- **tl;dr sec ニュースレター**（Clint Gibler） — 週次で最良のツール・talk・research を要約。継続学習の起点。
- **Critical Thinking Bug Bounty Podcast** / **Bug Bounty JP Podcast** — 最前線の技術とシーンを追う（後者は日本語）。

> 数値・CVSS・報奨額などは、必ず [NVD](https://nvd.nist.gov/) や各プラットフォームの公式発表など一次情報で裏取りすること。本書中の数値は執筆時点の二次資料に基づく。
